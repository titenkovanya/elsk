ОБНОВЛЕНИЕ УЖЕ СУЩЕСТВУЮЩЕГО САЙТА

1. Распакуйте архив на компьютере.
2. Откройте свой репозиторий GitHub и папку, из которой опубликован сайт (обычно корень).
3. Add file → Upload files. Перетащите всё содержимое распакованной папки вместе с assets и vendor. Загружайте содержимое, а не внешнюю папку и не сам ZIP. Файлы с совпадающими именами обновятся.
4. Сохраните изменения в ветку, которую использует GitHub Pages. Если создан запрос на слияние, завершите его.
5. Дождитесь успешного завершения публикации в Actions. Откройте сайт по прежней ссылке. Если видна старая версия, обновите страницу с Ctrl+F5 или откройте в приватном окне.

index.html должен остаться в той же папке, что и app.mjs и styles.css. Сохраняйте структуру assets и vendor. Настройки Pages и файл CNAME, если он у вас есть, удалять не нужно.

В этом архиве — последняя версия сайта: новая сцена на главном экране, шесть согласованных эффектов, обновлённый прогноз погоды и три работающих формата прогулки.

ЗЕЛЁНЫЙ ПУЛЬС — ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Распакуйте ZIP. На GitHub создайте новый PUBLIC-репозиторий, например zeleny-puls. Бесплатный GitHub Pages работает с публичным репозиторием.
2. Через Add file → Upload files загрузите содержимое распакованной папки. index.html должен лежать в корне репозитория; каталог assets и остальные файлы должны сохранить структуру. Сам ZIP на GitHub загружать не нужно. Нажмите Commit changes.
3. Откройте Settings → Pages. В Build and deployment выберите Source: Deploy from a branch, Branch: main, Folder: / (root). Нажмите Save.
4. Дождитесь публикации. Точную ссылку покажет раздел Settings → Pages. Обычно она выглядит как https://ИМЯ.github.io/zeleny-puls/. Не используйте пример вместо адреса своего проекта.
5. Проверьте ссылку без входа в GitHub и без VPN из Беларуси: на домашнем интернете и через мобильного оператора. Доступность зависит от сети; её нужно проверить до рассылки ссылки и печати QR.

Карта, прокрутка маршрута, выбор темпа, сравнение фото, день/вечер, доступность, страница проекта, автопрезентация и генератор QR работают без сервера. Погода загружается из Open-Meteo при наличии доступа к внешнему источнику; при сбое сайт сообщает, что свежие данные недоступны. QR и кнопка «Поделиться» сохраняют папку проекта в ссылке.

ОБРАТНАЯ СВЯЗЬ
GitHub Pages размещает статические файлы и не запускает серверную форму. В этой версии приём сообщений отключён; сайт не выдаёт сообщение за отправленное. Для включения формы нужен отдельный обработчик и база данных.
